# Edge-Swipe Navigation

Interactive predictive back and forward navigation. Drag from the left edge on the chat to go back to the list, or from the right edge on the list to go forward. One value drives the whole transition, so it follows your finger across the screen and commits past about a third of the width or on a fast flick. The back arrow and tapping a list row work too.

- `ClaudeStyleNavigation.swift`: the interaction, unchanged from the original file.
- `Usage.swift`: how to add it to an app target (iOS 17+).
