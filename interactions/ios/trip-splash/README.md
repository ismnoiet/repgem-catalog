# Trip Splash

A launch animation driven by a single clock. The wordmark spreads out from the orange dot, collapses into it, and the dot stretches into a gradient line that sweeps off the right edge. A circular sweep then reveals the home screen. Tap to replay.

- `TripsplashAnimation.swift`: the animation, unchanged from the original file.
- `Usage.swift`: how to add it to an app target (iOS 17+).
