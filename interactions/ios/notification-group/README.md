# Notification Group

An Android-style expandable notification group. The whole animation is driven by a single progress value, 0 collapsed to 1 expanded, and every element derives its own position and opacity from it, so tapping, dragging and flicking stay perfectly in sync. Drag down to expand, up to collapse; a quick flick counts even if it is short.

- `AndroidStyleNotificationGroup.swift`: the interaction, unchanged from the original file.
- `Usage.swift`: how to add it to an app target.
