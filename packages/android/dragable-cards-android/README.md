# Dragable Cards

A Trello-style board for Jetpack Compose. Long-press a card, drag it between columns, and watch the others slide out of the way as it snaps into place.

Video: `demo.mp4` and `poster.jpg` in this folder.

Source: https://github.com/ismnoiet/repgem-catalog/tree/main/packages/android/dragable-cards-android (MIT). Files here: `examples/QuickStart.kt`, `examples/ProjectBoard.kt` (the demo project board) and `examples/DragConfiguration.kt` (timing, appearance and column style).
